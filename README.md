# Friend Notes System

**Friend Notes System** is a Java-based application developed in **NetBeans** that allows students to share and access academic notes easily. The system promotes collaborative learning by enabling students to upload, view, and download notes among peers. When a note is downloaded, the uploader receives an email notification.

## Features

- **Upload Notes:** Students can upload notes in formats like PDF, DOC, etc.  
- **View Notes:** Browse notes shared by other students.  
- **Download Notes:** Download required notes for study purposes.  
- **Email Notification:** The uploader receives an email when their note is downloaded.  
- **User-Friendly Interface:** Built using Java Swing for an intuitive experience.

## Technologies Used

- **Java**  
- **NetBeans IDE**  
- **Java Swing** (for GUI)  
- **JavaMail API** (for sending email notifications)  
- **MySQL** (storing user info and note metadata)  

## Database Setup

The project includes a `.sql` file containing the database schema. You can download it and import it into your MySQL database to set up the project quickly.

1. Download the `.sql` file from the repository.  
2. Open **MySQL** or **phpMyAdmin**.  
3. Import the `.sql` file to create the necessary database and tables.  
4. Update the database connection details in the project if needed.
